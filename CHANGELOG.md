# Changelog

All notable changes to the `workspace-navigator` extension are documented in this file.

## [0.0.1] - 2026-07-26

### Added

- Added a TreeView that scans configured folders for `.code-workspace` files.
- Added workspace switching in the current window or a new window.
- Added file watching, manual refresh, and an active workspace indicator.
- Added actions to reveal the current workspace and expand all folders.
- Added scan-folder add and remove actions without deleting files from disk.
- Added configurable exclusion patterns and visible scan error reporting.
